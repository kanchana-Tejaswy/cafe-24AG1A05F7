Q1.2 - Difference commands:
git diff
git diff --staged

git diff shows unstaged changes in the working tree.
git diff --staged shows staged changes ready for the next commit.

Q1.4 - Why is git revert safer than git reset for a shared commit?
git revert creates a new commit to undo changes without rewriting shared history.

Q2.3 - Difference between git fetch and git pull:
git fetch downloads remote changes without integrating them into the current branch, while git pull fetches and integrates those changes into the current branch.
